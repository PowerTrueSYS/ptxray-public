What PTxray answers

Where does this AIX or IBM i system actually stand?

PTxray reads observable posture across lifecycle, patching, storage, performance, errors, resilience, security, configuration, and monitoring. It reports the evidence; it does not repair the host.

01 / BOUNDARY

Read-only

System configuration is inspected, never remediated. Requested report paths are the operator-controlled output.

02 / EGRESS

Assessment stays offline

Assessment execution does not fetch definitions, open network connections, send telemetry, or transmit report data.

03 / RUNTIME

Inspectable platform files

The AIX edition runs as one ksh88 file with AIX /bin/sh; the IBM i edition runs under PASE ksh.

04 / HONESTY

No fabricated status

Unavailable or ambiguous evidence can be NOT_ASSESSED; it is not silently reported as a pass.

Unpublished PTxray 1.5 release candidate

Candidate behavior, not a published download.

PTxray 1.5 is not a published release and is not available from releases/latest. Its AIX runner requires root, and its IBM i runner requires QSECOFR. The VIOS lane remains disabled pending live acceptance. Before assessment probes begin, the runner verifies and invokes the separate, adjacent, same-release digest-bound ptxray-defs.sh.

Connected mode is the default and attempts to download current signed definitions. --offline uses the last valid signed cache; --definitions-bundle verifies a local signed bundle and adjacent signature. The interactive menu presents update, cache, local-bundle, and continue-without-definitions choices. Old or stale definitions produce an explicit age warning.

The downloader discloses its two fixed HTTPS GET requests and observable DNS/TLS metadata before connecting, sends no request body or assessment data, and writes verified generations under /var/ptxray/definitions. Assessment probes then make no network calls, send no telemetry or assessment data, change no system configuration, and perform no remediation. A valid signed cache or local signed bundle supports an air-gapped assessment run.
